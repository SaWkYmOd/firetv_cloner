Fire OS 6 Guide

If you are using an older Fire TV device running Fire OS 6, please follow these specific steps to clone your apps:

Step 1: Open the Cloner and select any apk to start with.

Step 2: To reach the "Add to Parallel Space" or the "Arrow Button" at the bottom:

👉 Navigate down the RIGHT-HAND SIDE of the screen.

Using the left or center navigation may cause the focus to skip the button on OS 6.

Click "Add to Parallel Space". On the next screen you can add whatever apps you want.

FINAL UPDATE This version was difficult to optimize for older hardware. Please note that no further updates or work will be performed on the Fire OS 6 build. It is provided "as-is."
